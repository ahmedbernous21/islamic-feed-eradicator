Privacy policy

Islamic Feed Eradicator. Effective 26 October 2026.

Home Content policy Source

Islamic Feed Eradicator is a Chrome extension published by Ahmed Bernous. It replaces distracting feeds on YouTube, Facebook, LinkedIn, and Instagram with reminders stored inside the extension. This policy describes what the extension does with information.

Information stored on your device

The extension uses Chrome’s local storage on that browser profile only. It can store:

  • Whether the extension and each site or region are turned on.
  • Theme, translation, category, rotation, and snooze choices.
  • Favorites.
  • Personal notes you type, which are labeled as personal notes.
  • Which reminder was last shown.

That information is not uploaded by the extension. Uninstalling the extension, or clearing extension data in Chrome, removes it from the device.

Information the extension does not collect

The extension does not collect browsing history, account names, messages, passwords, or the contents of the pages you visit. It does not have Chrome’s history or tabs permissions. It does not include an account, an analytics service, or advertising. Reminder text is packaged with the extension and is not fetched from a server when you browse.

Permissions

Storage is used for the settings listed above. Host access is limited to YouTube, Facebook, LinkedIn, and Instagram so the extension can hide a feed on those sites and show a reminder in its place. The rest of each site stays in the page.

Suggest a Reminder

If you choose Suggest a Reminder, the extension opens a public GitHub issue form in a new browser tab. The extension does not send that form itself and does not contain a GitHub token. Anything you submit on GitHub is visible to anyone who can see the repository’s issues. Do not include an email address, phone number, or other private detail in a suggestion.

Remote code

The extension does not download or run code from the internet. Scripts, reminder text, and fonts are included in the package.

Sharing

The publisher does not sell settings, notes, or browsing information. The extension does not transfer them to a third party. GitHub receives only what you choose to type into a public issue after the form opens.

Children

The extension is not directed at children under 13, and it does not ask for a name, email address, or other contact detail.

Changes

If this policy changes, the updated page will be published here with a new effective date.

Contact
