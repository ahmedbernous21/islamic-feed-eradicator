Privacy policy

Islamic Feed Eradicator. Effective 2 November 2026.

Home Content policy Source

Islamic Feed Eradicator is a Chrome extension published by Ahmed Bernous. It replaces distracting feeds on YouTube, Facebook, LinkedIn, and Instagram with reminders stored inside the extension. This policy describes what the extension does with information.

Information stored on your device

The extension uses Chrome’s local storage on that browser profile only. It can store:

  • Whether the extension and each site or region are turned on.
  • Theme, translation, category, rotation, and snooze choices.
  • Favorites.
  • Personal notes you type, which are labeled as personal notes.
  • Which reminder was last shown.

That information is not uploaded by the extension. Uninstalling the extension, or clearing extension data in Chrome, removes it from the device.

Anonymous usage counts

Unless you turn Share anonymous usage off in Settings, the extension sends small usage counts to a server run by the publisher. Those counts are used to see whether people install the extension, leave it on, press Next, or keep a reminder on screen. A random install id is stored on the device so the same browser is not counted twice. The payload can include:

  • That random install id and the extension version.
  • Whether the extension was turned on or off.
  • That Next, Previous, Favorite, or Snooze was pressed, without which reminder it was.
  • Which supported site a reminder was visible on (YouTube, Facebook, LinkedIn, or Instagram) and for how many milliseconds.

You can turn this off at any time. Events already queued are not sent after it is off.

Information the extension does not collect

The extension does not collect browsing history, account names, messages, passwords, search terms, or the contents of the pages you visit. It does not have Chrome’s history or tabs permissions. It does not include an account or advertising. Reminder text is packaged with the extension and is not fetched from a server when you browse. Usage counts do not include URLs, reminder wording, personal notes, or favorites text.

Permissions

Storage is used for the settings listed above. Host access is limited to YouTube, Facebook, LinkedIn, and Instagram so the extension can hide a feed on those sites and show a reminder in its place. Scripting is used only to put that same bundled content script back on already-open tabs of those sites after you turn the extension off and on. ActiveTab is used when you click the toolbar icon so the popup can recognise the current site and restore the reminder on that tab. The rest of each site stays in the page.

Suggest a Reminder and Report

If you choose Suggest a Reminder, or Report on a reminder card, the extension opens a public GitHub issue form in a new browser tab. The extension does not send that form itself and does not contain a GitHub token. The report includes the reminder’s id, its citation, and the note you typed. Anything you submit on GitHub is visible to anyone who can see the repository’s issues. Do not include an email address, phone number, or other private detail in a suggestion or a report.

Remote code

The extension does not download or run code from the internet. Scripts, reminder text, and fonts are included in the package.

Sharing

The publisher does not sell settings, notes, or browsing information. GitHub receives only what you choose to type into a public issue after Suggest a Reminder or Report opens that form. Anonymous usage counts go only to the publisher’s metrics server, and only while Share anonymous usage is on.

Children

The extension is not directed at children under 13, and it does not ask for a name, email address, or other contact detail.
